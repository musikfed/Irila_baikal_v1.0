# Ирина Байкал 1.0 — описание системы

**Проект:** PegiNelab OS. Переносная ОС на основе Ubuntu для Acer Swift 3 SF314-41, загрузка с отдельного внешнего M.2 SSD по USB 3.0. Внутренний диск Windows 11 Pro не трогаем.

**Оборудование:** Ryzen 5 3500U (4 ядра, 8 потоков), Vega 8, 20 ГБ ОЗУ, Qualcomm Atheros QCA61x4A Wi-Fi, Realtek Audio, HD WebCam. Модули Linux (`amdgpu`, `ath10k_pci`, `snd_hda_intel`, `uvcvideo`) пока **только кандидаты**, проверка на Acer необходима.

**Интерфейс:** собственный Irina Shell в сине-зелёной палитре, всплывающее меню, локальный ИИ, Ирина Байкал Браузер (Qt WebEngine), круглая камера (видна, но выключена по умолчанию), селфи и ВКС через внешний Jitsi Meet.

**Языки:** RU/EN — переключатель языка оболочки. Раскладка клавиатуры на Windows: Win+Пробел; на Ubuntu XFCE/X11 — Alt+Shift после настройки XKB; для Wayland раскладка настраивается средствами окружения.

**Бесплатные программы:** LibreOffice Writer/Calc/Impress/Draw/Base/Math, GIMP, Inkscape, почта Thunderbird с несколькими аккаунтами, SIP-клиент Linphone, мини-игры Aisleriot/GNOME Mines/GNOME Mahjongg. Программы запускаются из меню только в Linux после установки. Asterisk — дополнительный сервер АТС, по умолчанию не ставится.

**Важное устройство диска:** конечному образу необходим отдельный раздел постоянных данных (желательно LUKS2), чтобы почта, SIP-аккаунты, документы и настройки не исчезали после перезагрузки при OverlayFS в ОЗУ.

**Статус:** оболочка v0.5 — прототип. Готовый загрузочный, подписанный и проверенный на Acer `irina_baikal_1.0.img` **ещё не создан**. Windows-версия демонстрирует меню, но не запускает Ubuntu-приложения.

Инструкции: [Языки, офис, графика, связь](LOCALIZATION_AND_APPS.md).
