# Acer SF314-41: драйверы и прошивка внешнего SSD

## Известное железо

* Ryzen 5 3500U, Vega 8: `amdgpu`, Mesa, `linux-firmware`.
* Qualcomm Atheros **QCA61x4A**: кандидат `ath10k_pci`, пакет `linux-firmware` (семейство QCA6174); PCI ID уточняется при первом тесте Linux.
* Realtek Audio + HDMI AMD: кандидаты `snd_hda_intel`, ALSA/PipeWire.
* **HD WebCam**: кандидат `uvcvideo` для устройств USB Video Class.
* Bluetooth/перо: совместимость и конкретные модули пока не подтверждены.

Ubuntu VM в Windows не видит встроенную периферию так же, как реальный Acer. Проверки выполняются после загрузки с SSD:

```bash
lspci -nnk
lsusb
lsmod | grep -E 'amdgpu|ath10k_pci|snd_hda_intel|uvcvideo'
nmcli device
v4l2-ctl --list-devices
journalctl -k -b | grep -Ei 'ath10k|amdgpu|firmware|uvc'
```

Команды только диагностические. Изображение, звук, микрофон, Wi-Fi, Wi-Fi после сна и аппаратное ускорение проверить вручную.

## Запись в Windows

1. Собрать и протестировать `irina_baikal_1.0.img` на Linux VM и проверить его SHA-256.
2. Подключить **только внешний** M.2 SSD 256 ГБ USB 3.0. **Внутренний 512 ГБ с Windows никогда не использовать как цель.**
3. В PowerShell выполнить **только чтение**: `powershell -NoProfile -File .\windows\Check-IrinaTarget.ps1`.
4. Проверить `USB`, размер, модель, отсутствие системного/загрузочного статуса. Физически отсоединить и снова подключить SSD, убедиться, что исчезает и появляется нужная строка.
5. Через проверенную программу Rufus https://rufus.ie/ выбрать готовый `.img`, а затем **именно внешний SSD**. Подтвердить уничтожение только его содержимого.
6. Перезагрузить Acer и выбрать внешний UEFI SSD через F12, если меню активировано в BIOS/UEFI.

**Не форматировать диск заранее:** готовый `.img` содержит GPT, EFI и Linux-разделы. **В текущем репозитории нет проверенного загрузочного IMG.** «Программа-прошивальщик на Python» пока не нужна: повышает вероятность стирания не того устройства.

Папка `browser/` не вмешивается в разделы дисков. Не публикуем идентификаторы Windows, серийные номера и пароли в GitHub.
