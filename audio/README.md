# Ирина Байкал 1.0 — звуковое интро

## Байкальская заставка v1.0 — оригинальный шум волн

**Первый аппаратный запуск подтверждён 29 октября 2026:** Acer Swift 3 SF314-41 уже загрузил рабочий стол с подписанным UEFI-загрузчиком и записываемым ext4. Заставка играет **после входа в XFCE**, когда уже доступен PipeWire/ALSA, а не внутри UEFI и не во время загрузки ядра.

Генератор `audio/generate_intro.py` теперь по умолчанию делает **процедурный шум байкальских волн** (никаких чужих записей, лицензий или сетевых сервисов) с голосом eSpeak на русском:

> «Ирина Байкал. Версия один ноль. Создана за пять часов. Добро пожаловать!»

Фраза «пять часов» — шуточная памятная реплика автора об этапе первых испытаний, не показатель полного жизненного цикла разработки или качества.

```bash
python3 audio/generate_intro.py --theme lake --output /tmp/irina-baikal-lake.wav
```

Прежний космический вариант сохранён: `--theme cosmic`. Для натурального женского голоса позднее можно использовать только собственную/лицензированную WAV-запись через `--voice-wav`. eSpeak остаётся роботизированным; генерация не требует интернета после установки инструментов.

**Важно:** уже записанная на USB версия IMG не меняется от GitHub-коммита. Новый MP3 попадает в будущую сборку или может быть установлен позднее из отдельного безопасного обновления, но текущий работающий SSD не перепрошивается автоматически. Чтобы выключить интро, в Linux создаётся `~/.config/irina/disable-intro`; графическое переключение пока в разработке. Громкость подбирается в ОС, не на уровне прошивки.

# История: космический прототип v0.7

**Звуковой образ:** воздушный космический фон, мягкий низкий синтезатор, несколько хрустальных импульсов и тихий женский синтетический тембр:

> «Ирина Байкал систем один точка ноль»

**Версия v0.7:** около 10,7 секунды, стерео 44,1 кГц. Фон сохранён, а речевая дорожка пересобрана с приоритетом разборчивости.

**Голос:** автономный прототип создаётся через eSpeak (`ru+f3`), без дыхательного шума, который ранее маскировал слова. Фраза озвучивается двумя частями с паузой; музыка приглушается примерно на 13 дБ на время речи, эхо убрано. Конец речи контролируется по реальной длине WAV, чтобы не обрывать фразу. eSpeak может использовать неполный русский словарь — произношение остаётся синтетическим и не гарантированно естественным. Это не запись женщины и не настоящий шёпот. Генератор может принять записанную или лицензированную WAV-дорожку через `--voice-wav`. Не добавлять чужие записи без разрешения.

## Генерация

Workflow `.github/workflows/build-intro.yml` устанавливает numpy, scipy, espeak и ffmpeg, создаёт `ui/web/assets/irina_intro.mp3` и публикует GitHub Actions artifact. При push на main он также коммитит MP3 в репозиторий.

Локально на Linux:
```bash
sudo apt-get install espeak ffmpeg
python3 -m pip install numpy scipy
python3 audio/generate_intro.py --output /tmp/irina_intro.wav
ffmpeg -y -i /tmp/irina_intro.wav -codec:a libmp3lame -qscale:a 3 ui/web/assets/irina_intro.mp3
```

Своё голосовое WAV (PCM 16 bit): `python audio/generate_intro.py --voice-wav /path/to/voice.wav --output /tmp/irina_intro.wav`. Нужна запись с согласованной фразой.

## Воспроизведение

Ubuntu: после входа в рабочий сеанс XFCE, не при старте UEFI. `audio/play_intro.sh` использует `mpg123` или `ffplay`. Скрипт `ui/install_ubuntu.sh` копирует интерфейс и аудио и создаёт XDG-autostart запись. Выполнять только в тестовой Ubuntu VM или в явно выбранной Linux-системе.

Windows: для предпросмотра кнопка **♪ Звук старта** в быстрых настройках оболочки. Автовоспроизведение в браузерах может блокироваться; никакого звука при обновлении страницы не запускаем.

Отключение интро на Linux:
```bash
mkdir -p "$HOME/.config/irina"
touch "$HOME/.config/irina/disable-intro"
```

Включение: `rm "$HOME/.config/irina/disable-intro"`. Для сохранения настроек и почты в будущей Read-Only ОС нужен постоянный DATA-раздел SSD.

**Статус:** звуковой прототип и скрипты, не готовый Acer-проверенный загрузочный образ.

## Проверка качества v0.7

- Генератор динамически определяет длину синтезированной речи: аудио не может завершиться раньше чем через 0,8 с после её конца.
- Голосовые дорожки произносят отдельно «Ирина Байкал» и «Систем один точка ноль», с паузой ~450 мс.
- Музыка сохраняет космическую фактуру, но заметно тише во время голоса.
- Оценка естественности русской речи требует прослушивания человеком. В будущем можно подать лицензированную русскоязычную женскую TTS-запись через `--voice-wav`.
