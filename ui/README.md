# Irina Shell v0.5 — прототип рабочего стола

**Это интерактивная оболочка, а не готовая загружаемая Linux ОС.** Работает локально в браузере Windows 11 Pro и Ubuntu. Не заменяет системный рабочий стол XFCE.

## Запуск

**Windows 11 Pro, Acer Swift 3 SF314-41**: Python и uv **уже установлены**, ничего скачивать не нужно. Доступны Python **3.14.4, 3.13.13 и 3.12.9**, uv **0.11.15**. Для предсказуемого запуска выберите уже установленный Python **3.13**: из корня репозитория выполните `py -3.13 ui/irina_shell.py`. Либо дважды щёлкните `ui/start_windows.bat` (этот BAT выбирает стандартный Python 3 в системе).

**Ubuntu 24.04**: `bash ui/start_linux.sh` (Python 3 уже есть в стандартной Ubuntu). Браузер откроется на `http://127.0.0.1:8765/` (по умолчанию фиксированный локальный порт; можно изменить через `IRINA_PORT`). Без доступа к интернету функционируют окна, темы, меню и камера; для ВКС нужен интернет.

## Новое в v0.5

- Интерфейс на **русском и английском** (кнопка RU/EN справа вверху). Переключение раскладки ОС отдельно: Windows Win+Пробел, Linux XFCE/X11 Alt+Shift после настройки XKB.
- **Круг камеры виден по умолчанию, но видеозахват выключен**. Крестик убирает его, меню возвращает. Язык и видимость сохраняются в `localStorage` при постоянном профиле браузера.
- В меню добавлены офис, графика, почта (Thunderbird), SIP (Linphone) и мини-игры. **Локальные приложения запускаются только на Linux, если отдельно установлены**; в Windows меню демонстрационное.
- Сценарий установки и полная спецификация: [документация](../docs/LOCALIZATION_AND_APPS.md).
- Для постоянной почты и настроек в будущей ОС нужен writable `/home` на SSD, иначе OverlayFS в RAM всё сбросит.

## Что уже сделано

- Три темы: «Байкал» (сине-зелёная), «Тайга» (зелёная), «Ночь».
- Всплывающее меню, панель задач и перетаскиваемые окна.
- Круглая плавающая веб-камера со включением/выключением и сохранением PNG-селфи на локальный диск. Разрешение на использование камеры запрашивает браузер.
- Раздел «Видеосвязь»: создаёт случайное имя комнаты, после явного нажатия открывает встречу **на внешнем сервисе meet.jit.si**. Это пока **не** собственный сервер ВКС. Камера/микрофон для встречи разрешаются отдельно на сайте.
- Локальный чат «Ирина» через Ollama HTTP API (необязательно): нужен работающий Ollama с `ollama pull qwen3:1.7b`, можно задать `IRINA_MODEL`.
- Выбор локальных файлов без их загрузки на сервер; ввод URL и открытие сайта во внешней вкладке.
- Оригинальные векторные обои, стилизованные под озеро Байкал: для фотозаставки требуется отдельный снимок с подходящей лицензией.

## Безопасность и ограничения

- HTTP-сервер привязан **только** к `127.0.0.1`, порт выбирается автоматически, поэтому интерфейс нельзя открыть извне по сети.
- Камера **не** включается автоматически. Предпросмотр локален, фото скачивается браузером; мы не отправляем кадры на backend.
- При переходе в Jitsi Meet внешняя площадка получает данные согласно собственным условиям, когда пользователь предоставляет разрешения. Для самостоятельной ВКС нужны сигналинг, STUN/TURN, медиасервер или P2P WebRTC и меры защиты.
- Это приложение ещё не управляет Wi-Fi, электропитанием, журналами ОС и аппаратными настройками: браузеру такие функции недоступны.
- На данный момент UI запускается поверх Firefox/Chromium/Edge. В Ubuntu позже нужно установить режим киоска или собственную оконную оболочку, реализовать автозапуск и интеграцию с XFCE.

## Структура

- `irina_shell.py` — локальный HTTP-сервер + необязательный прокси к Ollama.
- `web/index.html` — разметка рабочего стола.
- `web/style.css` — синяя и зелёная темы, окна, меню.
- `web/app.js` — взаимодействия, камера, видеосвязь, приложения.
- `web/assets/` — собственный SVG-логотип и векторный Байкал.

Скопируйте `ui/` в образ Ubuntu и запустите через автозапуск пользовательского сеанса после реальных испытаний. Никаких драйверов и разрешений на доступ к Windows-разделу оболочка не требует.

### Автозапуск в Ubuntu с XFCE (опционально)

После ручной проверки выполните `bash ui/install_ubuntu.sh`. Скрипт копирует файлы в `/opt/irina/ui` и добавляет автозапуск в графический сеанс через `/etc/xdg/autostart/irina-shell.desktop`. Он **не** меняет загрузчик и не форматирует диски. Для отключения: `sudo rm /etc/xdg/autostart/irina-shell.desktop` (проверьте путь перед удалением).

### Железо Acer: что уже известно

На компьютере есть встроенная **HD WebCam** (круглое селфи), **Realtek Audio** (микрофон/динамики), **AMD Radeon Vega 8** (графика) и **Qualcomm Atheros QCA61x4A** (Wi‑Fi, **не Intel**). Windows показывает поддержку ввода пером, но совместимость с Linux предстоит проверить. Подробнее — [профиль Acer / Windows Host](../docs/ACER_SF314-41_WINDOWS_HOST.md).

Для текущего локального HTTP-сервера не нужны `pip install`, виртуальное окружение и повторная установка Python. `uv` пригодится при развитии Python-модулей. Windows и внутренний SSD не затрагиваются.
