# Ирина Байкал Браузер — Qt WebEngine, v0.4 (прототип)

Собственный **сине-зелёный интерфейс браузера**, вкладки, назад/вперёд, поиск, стартовая страница с оригинальной векторной иллюстрацией Байкала. Реальные веб-страницы отображает **Qt WebEngine (Chromium)**; свой HTML/JS-движок не разрабатываем.

## Windows 11 Pro (Acer SF314-41)

Уже установлено: uv 0.11.15, Python 3.12 / 3.13 / 3.14. Ничего переустанавливать не надо. В PowerShell из корня репозитория:

```powershell
uv venv --python 3.13 .venv
uv pip install --python .venv\Scripts\python.exe -r browser\requirements.txt
.\.venv\Scripts\python.exe browser\main.py
```

Либо запустить `browser\start_windows.bat` (он подготавливает окружение и установит зависимости, если требуется). Для первой установки нужен интернет: Qt WebEngine — крупная зависимость. Протестировать функции без GUI:

```powershell
py -3.13 -m unittest discover -s browser\tests -v
```

## Ubuntu 24.04

Python 3.12, графическая сессия и рабочие библиотеки Qt/WebEngine обязательны. При установленном `uv`:

```bash
bash browser/start_linux.sh
```

В ранних сборках Ubuntu может понадобиться пакет ОС `libxcb-cursor0`, графическая среда Wayland/X11 и библиотеки Qt; это проверяется в реальной VM.

## Безопасность и ограничения

- Доступ к камере/микрофону **никогда не предоставляется автоматически**: браузер показывает отдельный запрос, по умолчанию — отказ.
- Удалённые поисковые запросы идут через DuckDuckGo. Движок использует инфраструктуру и настройки Qt WebEngine. **Это прототип, а не защищённый приватный браузер**, нет встроенного блокировщика рекламы, синхронизации, менеджера паролей, защитного sandbox-аудита и гарантированного пути всех загрузок.
- Встреча ВКС открывается через внешний `meet.jit.si` и требует сети и явного разрешения.
- Локальная ИИ-ссылка ведёт только к статусу `127.0.0.1:11434`; полноценный интерфейс ИИ уже разрабатывается отдельно в `ui/`.
- Приложение пока **не встроено** в установочный `.img`; образ Ubuntu ещё не проверен.
- Компонент Qt / Qt WebEngine распространяется на условиях лицензий Qt. Перед коммерческой дистрибуцией проверить обязательства LGPL/GPL.

## План интеграции

Добавить пункт «Браузер» в основную оболочку Irina Shell (через локальную доверенную команду), затем включить автозапуск/пакетирование в Ubuntu и проверить камеру, WebRTC, звук, аппаратное ускорение Vega 8.
