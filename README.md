# PegiNelab OS — Ирина Байкал 1.0

**Статус: ранний прототип (v0.2); загрузочный IMG ещё не выпущен.**

Независимая переносная ОС для **Acer Swift 3** (AMD Ryzen 5 3500U, Radeon Vega 8, 20 ГБ RAM), которая запускается с **внешнего M.2 SSD 256 ГБ по USB 3.0** через меню UEFI F12. Основной Windows 11 Pro не заменяется и не форматируется.

## Как задумано

- База — **Ubuntu 24.04 LTS** в минимальной сборке, позже можно перейти на 26.04 LTS.
- Собирается внутри **Ubuntu 24.04 VM на Windows 11 Pro / Hyper-V**, затем сохраняется в `irina_baikal_1.0.img`.
- IMG уже содержит **GPT**, `EFI (FAT32)`, системный `ext4` с файлом `SquashFS`: предварительное форматирование SSD в Windows **не нужно**.
- Загрузка: экспериментальный UEFI Rust → проверенное ядро/initramfs → SquashFS только чтение + OverlayFS в RAM → XFCE → локальный Ollama + Hrag.
- Оформление: лицензированное фото озера Байкал, название «Ирина Байкал 1.0».
- Готовый образ с Qwen3 8B может быть больше 5 ГБ. Для компактного прототипа предусмотрена Qwen3 1.7B.

## Windows 11 Pro → внешнее SSD

1. Собрать или получить `irina_baikal_1.0.img` **и** `.img.sha256`.
2. Подключить **внешний** USB M.2 SSD 256 ГБ; проверить модель и ёмкость в диспетчере дисков Windows.
3. При наличии PowerShell-проверки `windows/Check-IrinaTarget.ps1` выполнить её, **не записывая ничего на диск**.
4. Открыть **Rufus** с официального сайта https://rufus.ie/, указать `.img`, выбрать только внешний SSD, выбрать DD-режим при наличии и подтвердить удаление данных на выбранном SSD.
5. Выключить компьютер, включить Acer и выбрать внешний EFI SSD через F12 (если меню активировано в UEFI).

**Важно:** сама запись полностью уничтожает прежнее содержимое выбранного SSD, но никак не должна затрагивать внутренний диск Windows. Не запускайте запись, пока не уверены в выборе носителя.

## Дальнейшие исходники

В разработке: `prepare_source.sh`, `bake_image.sh`, `smart_aida64.py`, Rust `bootloader/`, `initramfs/`, `ai/`, `systemd/`, `qa_qemu.sh`, `windows/`, конфигурация Acer, оформление Байкал. Готового подписанного и проверенного на Acer релиза **нет**. Источники этого прототипа подготавливаются отдельно.

Защита от физической подмены требует подписанного и доверенного `BOOTX64.EFI`; контроль SHA-256 без корня доверия не равен Secure Boot.

Локальные идентификаторы Windows, Device ID, Product ID, серийные номера и Wi-Fi пароли в публичный репозиторий не включаем.

## Irina Shell · сине-зелёная оболочка (v0.3)

Рабочий прототип оболочки со всплывающим меню, сине-зелёными окнами, круглым окном для селфи и пунктом ВКС находится в каталоге [ui/](ui/README.md). Он работает из браузера на Windows 11 и Linux, а затем может устанавливаться на Ubuntu.

- Windows: установите Python 3 и запустите `ui/start_windows.bat`.
- Ubuntu: `bash ui/start_linux.sh`.
- ВКС: по явному нажатию открывается внешний Jitsi Meet. Собственного сервера видеосвязи пока нет.
- Камера: только после явного разрешения, снимки остаются локальными.

**Загрузочного IMG пока нет**: интерфейс работает как прототип, готовность ОС не подразумевается.
