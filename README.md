# PegiNelab OS — Ирина Байкал 1.0

**Статус: ранний прототип (UI v0.3); загрузочный IMG ещё не выпущен.**

Независимая переносная ОС для **Acer Swift 3 SF314-41** (AMD Ryzen 5 3500U, Radeon Vega 8, 20 ГБ RAM), которая запускается с **внешнего M.2 SSD 256 ГБ по USB 3.0** через меню UEFI F12. Основной Windows 11 Pro не заменяется и не форматируется.

## Как задумано

- База — **Ubuntu 24.04 LTS** в минимальной сборке, позже можно перейти на 26.04 LTS.
- Собирается внутри **Ubuntu 24.04 VM на Windows 11 Pro / Hyper-V**, затем сохраняется в `irina_baikal_1.0.img`.
- IMG уже содержит **GPT**, `EFI (FAT32)`, системный `ext4` с файлом `SquashFS`: предварительное форматирование SSD в Windows **не нужно**.
- Загрузка: экспериментальный UEFI Rust → проверенное ядро/initramfs → SquashFS только чтение + OverlayFS в RAM → XFCE → локальный Ollama + Hrag.
- Оформление: лицензированное фото озера Байкал, название «Ирина Байкал 1.0».
- Готовый образ с Qwen3 8B может быть больше 5 ГБ. Для компактного прототипа предусмотрена Qwen3 1.7B.

## Windows 11 Pro → внешнее SSD

1. Собрать или получить `irina_baikal_1.0.img` **и** `.img.sha256`.
2. Подключить **внешний** USB M.2 SSD 256 ГБ; проверить модель и ёмкость в диспетчере дисков Windows.
3. При наличии PowerShell-проверки `windows/Check-IrinaTarget.ps1` выполнить её, **не записывая ничего на диск**.
4. Открыть **Rufus** с официального сайта https://rufus.ie/, указать `.img`, выбрать только внешний SSD, выбрать DD-режим при наличии и подтвердить удаление данных на выбранном SSD.
5. Выключить компьютер, включить Acer и выбрать внешний EFI SSD через F12 (если меню активировано в UEFI).

**Важно:** сама запись полностью уничтожает прежнее содержимое выбранного SSD, но никак не должна затрагивать внутренний диск Windows. Не запускайте запись, пока не уверены в выборе носителя.

## Дальнейшие исходники

В разработке: `prepare_source.sh`, `bake_image.sh`, `smart_aida64.py`, Rust `bootloader/`, `initramfs/`, `ai/`, `systemd/`, `qa_qemu.sh`, `windows/`, конфигурация Acer, оформление Байкал. Готового подписанного и проверенного на Acer релиза **нет**. Источники этого прототипа подготавливаются отдельно.

Защита от физической подмены требует подписанного и доверенного `BOOTX64.EFI`; контроль SHA-256 без корня доверия не равен Secure Boot.

Локальные идентификаторы Windows, Device ID, Product ID, серийные номера и Wi-Fi пароли в публичный репозиторий не включаем.

## Irina Shell · сине-зелёная оболочка (v0.3)

Рабочий прототип оболочки со всплывающим меню, сине-зелёными окнами, круглым окном для селфи и пунктом ВКС находится в каталоге [ui/](ui/README.md). Он работает из браузера на Windows 11 и Linux, а затем может устанавливаться на Ubuntu.

- Windows: Python уже установлен; рекомендуется запуск `py -3.13 ui/irina_shell.py` из корня проекта либо `ui/start_windows.bat`.
- Ubuntu: `bash ui/start_linux.sh`.
- ВКС: по явному нажатию открывается внешний Jitsi Meet. Собственного сервера видеосвязи пока нет.
- Камера: только после явного разрешения, снимки остаются локальными.

**Загрузочного IMG пока нет**: интерфейс работает как прототип, готовность ОС не подразумевается.

## Подтверждённая конфигурация Acer / Windows 11 Pro

Источник — скриншоты Windows «О системе», «Диспетчер устройств» и вывод PowerShell владельца. **Полное сканирование чипсетов перед каждой сборкой не нужно.** Детали и безопасные команды: [Инструкция по Host](docs/ACER_SF314-41_WINDOWS_HOST.md). Машиночитаемый профиль: [hardware/acer_swift3_sf314-41.json](hardware/acer_swift3_sf314-41.json).

- **Ноутбук:** Acer Swift 3 **SF314-41**; Ryzen 5 3500U (4 ядра, 8 потоков); Radeon Vega 8; 20 ГБ ОЗУ.
- **Windows:** 11 Pro, 26H2; в наличии **uv 0.11.15**, **Python 3.14.4 / 3.13.13 / 3.12.9**. Повторно ставить Python или uv не надо.
- **Wi-Fi исправлен:** **Qualcomm Atheros QCA61x4A**, **не Intel**; в Ubuntu планировать `ath10k_pci` и `linux-firmware`, подтвердить PCI ID при первой Linux-загрузке.
- **Существующая периферия:** HD WebCam, Realtek Audio, AMD HDMI Audio, контроллеры AMD USB 3.x, Bluetooth и поддержка ввода пером по данным Windows.
- **Диски не путать:** внутренний M.2 SSD около **512 ГБ** (по данным владельца, Windows **сохраняем**), внешний USB M.2 SSD **256 ГБ** — **только он предназначен для записи IMG**. Общая сводка Windows «219 из 589 ГБ» не определяет физический диск.
- **Запуск UI без установки зависимостей** из корня репозитория: `py -3.13 ui/irina_shell.py`. Текущий UI использует стандартную библиотеку Python; для разработки новых модулей можно использовать установленный `uv`.

**Приватность:** идентификаторы устройства, продукта Windows и серийные номера с пользовательских скриншотов в публичный репозиторий не копируются.

## Ирина Байкал Браузер · Qt WebEngine v0.4

Создан отдельный **нативный браузер** с сине-зелёным интерфейсом, вкладками, адресной строкой, поиском, собственной домашней страницей «Байкал» и явным запросом разрешения на камеру/микрофон. Исходники и ограничения — [browser/README.md](browser/README.md), конфигурация SSD и драйверов — [docs/FLASHING_AND_DRIVERS.md](docs/FLASHING_AND_DRIVERS.md).

Windows 11 Pro: повторно ставить Python/uv **не нужно**. Установлены `uv 0.11.15`, `Python 3.14.4 / 3.13.13 / 3.12.9`. Используем **Python 3.13** в отдельном виртуальном окружении:

```powershell
uv venv --python 3.13 .venv
uv pip install --python .venv\Scripts\python.exe -r browser\requirements.txt
.\.venv\Scripts\python.exe browser\main.py
```

Также можно запустить `browser\start_windows.bat`. Тест адресов (не требует Qt): `py -3.13 -m unittest discover -s browser\tests -v`. **Графический запуск на Acer пока не проверен.**

**Ответы на архитектурные вопросы:** для записи IMG на внешний SSD 256 ГБ достаточно Rufus — самописный Python-прошивальщик не обязателен; при этом внутренний SSD Windows 512 ГБ ни в коем случае не выбирать. Rust пригодится позднее для доверенного UEFI-загрузчика, ассемблер пока **не требуется**; первая загружаемая версия может использовать стандартный GRUB. Linux-драйверы `amdgpu`, `ath10k_pci`, `snd_hda_intel`, `uvcvideo` — обоснованные кандидаты, но их работоспособность нужно проверить на реальном Acer. На Wi-Fi установлен Qualcomm Atheros QCA61x4A (**не Intel**).
