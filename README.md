### Самый простой вариант с Windows 11

1. Открыть GitHub → Actions → **Build Irina Baikal read-only IMG** → **Run workflow**.
2. Выбрать `core` и `5120` MiB, затем запустить сборку. Это запрос на **создание файла образа на GitHub**, а не на SSD Acer.
3. **Если** workflow завершится успешно, скачать Artifact `irina-baikal-1.0-readonly-img`, распаковать IMG и SHA256 в Windows. GitHub может ограничивать размер артефакта и доступное место на runner.
4. Запустить `py -3.13 scripts\flash_irina.py --image "C:\путь\irina_baikal_1.0.img"`: проверит SHA и покажет физические диски **только чтение**.
5. Rufus → выбрать **внешний USB M.2 SSD 256 ГБ** → RAW/DD-запись → выключить Acer → F12 → внешний SSD.

SSD уже пустой: дополнительное форматирование не нужно. **Внутренний Windows SSD не трогаем**. Сборка на GitHub и загрузка на Acer пока не проверены; до появления завершённого Artifact не считать, что образ существует. Варианты локальной сборки через WSL2 либо Ubuntu Live-USB тоже описаны в руководстве.

Внимание: оригинальный старый [16 GiB RW-ext4 сборщик](scripts/build_irina_img.sh) оставлен в проекте только как **устаревший прототип** и НЕ соответствует первоначальному ТЗ с SquashFS. Не выбирать его для первой Read-Only сборки. Новый образ пока использует неподписанный GRUB, а не Rust Secure Boot; Ollama/Qwen добавляются только с заранее полученными Linux-моделью и бинарником. В базовом `core` образе модель отсутствует. Временные изменения `/home` пропадают при перезапуске до настройки постоянного DATA-раздела.

# PegiNelab OS — Ирина Байкал 1.0

## ВАЖНО: основной путь сборки — Source → SquashFS → UEFI, без обязательной VM

Первоначальное ТЗ **не предусматривало установку обычной Ubuntu в виртуальную машину и создание постоянного ext4-корня**. Основной вариант теперь описан в [DIRECT_NO_VM_READONLY_PLAN.md](docs/DIRECT_NO_VM_READONLY_PLAN.md).

- **Windows 11 Pro** на Acer — пульт разработки и программа записи IMG на пустой USB M.2 SSD 256 ГБ, **не Linux-источник**.
- Linux Source должен быть работающей Ubuntu/Debian (например, Ubuntu 24.04 Live-USB) либо Linux-средой WSL2 для подготовки системы. Если источник Ubuntu отсутствует, можно использовать официальный [Ubuntu Base amd64](https://cdimages.ubuntu.com/ubuntu-base/releases/24.04/release/) и добавить ядро/пакеты.
- Boot: UEFI → Linux kernel + casper initramfs → Read-Only `filesystem.squashfs` → OverlayFS в RAM. Файлы пользователя — отдельно на постоянном DATA-разделе SSD.
- **Проверка через QEMU/KVM опциональна**. Первая загрузка на Acer по F12 может быть непосредственным тестом с риском ошибки загрузки.
- Старый `scripts/build_irina_img.sh` **не соответствует финальному ТЗ**: создаёт экспериментальный 16-GiB образ с записываемым ext4 root.
- Rust EFI Secure Boot, Hrag, модель Ollama и компактная сборка **вместе ещё не подтверждены**. Готовый `irina_baikal_1.0.img` в репозитории пока отсутствует.

## Как задумано

- База — **Ubuntu 24.04 LTS** в минимальной сборке, позже можно перейти на 26.04 LTS.
- Собирается внутри **Ubuntu 24.04 VM на Windows 11 Pro / Hyper-V**, затем сохраняется в `irina_baikal_1.0.img`.
- IMG уже содержит **GPT**, `EFI (FAT32)`, системный `ext4` с файлом `SquashFS`: предварительное форматирование SSD в Windows **не нужно**.
- Загрузка: экспериментальный UEFI Rust → проверенное ядро/initramfs → SquashFS только чтение + OverlayFS в RAM → XFCE → локальный Ollama + Hrag.
- Оформление: лицензированное фото озера Байкал, название «Ирина Байкал 1.0».
- Готовый образ с Qwen3 8B может быть больше 5 ГБ. Для компактного прототипа предусмотрена Qwen3 1.7B.

## Windows 11 Pro → внешнее SSD

1. Собрать или получить `irina_baikal_1.0.img` **и** `.img.sha256`.
2. Подключить **внешний** USB M.2 SSD 256 ГБ; проверить модель и ёмкость в диспетчере дисков Windows.
3. При наличии PowerShell-проверки `windows/Check-IrinaTarget.ps1` выполнить её, **не записывая ничего на диск**.
4. Открыть **Rufus** с официального сайта https://rufus.ie/, указать `.img`, выбрать только внешний SSD, выбрать DD-режим при наличии и подтвердить удаление данных на выбранном SSD.
5. Выключить компьютер, включить Acer и выбрать внешний EFI SSD через F12 (если меню активировано в UEFI).

**Важно:** сама запись полностью уничтожает прежнее содержимое выбранного SSD, но никак не должна затрагивать внутренний диск Windows. Не запускайте запись, пока не уверены в выборе носителя.

## Подтверждённая конфигурация Acer / Windows 11 Pro

Источник — скриншоты Windows «О системе», «Диспетчер устройств» и вывод PowerShell владельца. **Полное сканирование чипсетов перед каждой сборкой не нужно.** Детали и безопасные команды: [Инструкция по Host](docs/ACER_SF314-41_WINDOWS_HOST.md). Машиночитаемый профиль: [hardware/acer_swift3_sf314-41.json](hardware/acer_swift3_sf314-41.json).

- **Ноутбук:** Acer Swift 3 **SF314-41**; Ryzen 5 3500U (4 ядра, 8 потоков); Radeon Vega 8; 20 ГБ ОЗУ.
- **Windows:** 11 Pro, 26H2; в наличии **uv 0.11.15**, **Python 3.14.4 / 3.13.13 / 3.12.9**. Повторно ставить Python или uv не надо.
- **Wi-Fi исправлен:** **Qualcomm Atheros QCA61x4A**, **не Intel**; в Ubuntu планировать `ath10k_pci` и `linux-firmware`, подтвердить PCI ID при первой Linux-загрузке.
- **Существующая периферия:** HD WebCam, Realtek Audio, AMD HDMI Audio, контроллеры AMD USB 3.x, Bluetooth и поддержка ввода пером по данным Windows.
- **Диски не путать:** внутренний M.2 SSD около **512 ГБ** (по данным владельца, Windows **сохраняем**), внешний USB M.2 SSD **256 ГБ** — **только он предназначен для записи IMG**. Общая сводка Windows «219 из 589 ГБ» не определяет физический диск.
- **Запуск UI без установки зависимостей** из корня репозитория: `py -3.13 ui/irina_shell.py`. Текущий UI использует стандартную библиотеку Python; для разработки новых модулей можно использовать установленный `uv`.

**Приватность:** идентификаторы устройства, продукта Windows и серийные номера с пользовательских скриншотов в публичный репозиторий не копируются.

## Первый IMG-сборщик для пустого внешнего SSD 256 ГБ

Сборщик предварительной версии добавлен: [scripts/build_irina_img.sh](scripts/build_irina_img.sh). Подробная пошаговая инструкция под Windows 11 Pro: [docs/BUILD_IMAGE_WINDOWS11.md](docs/BUILD_IMAGE_WINDOWS11.md).
